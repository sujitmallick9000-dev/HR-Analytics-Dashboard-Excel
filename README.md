📊 HR Analytics Dashboard
An interactive Excel-based HR Analytics Dashboard designed to analyze workforce metrics, employee distribution, salary trends, and key HR KPIs. Built using Pivot Tables, Pivot Charts, Slicers, and Advanced Excel techniques.

🔍 Project Overview
This project focuses on transforming raw HR data into meaningful insights that help organizations understand workforce patterns, employee demographics, and HR performance indicators.
The dashboard provides a clear, visual summary of employee headcount, attrition, salary trends, tenure distribution, and more.

🎯 Objectives
Analyze employee distribution across departments, locations, gender, age groups, and tenure.

Track key HR KPIs such as headcount, active employees, leavers, average salary, average tenure, and training hours.

Identify workforce trends and patterns to support HR decision-making.

Build an interactive dashboard using Excel Pivot Tables, Charts, and Slicers.
